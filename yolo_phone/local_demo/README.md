# 本机临时测试

使用针对性补充训练的 `multiview_targeted_round2_20261021_yolo11n/weights/best.pt`（第 51 轮）。
服务仅监听 `127.0.0.1`，图片和视频不保存到训练集；推理尺寸固定 640，默认阈值 0.35（2026-10-22 按验证集选定）。

启动（在项目根目录）：

```bash
./.venv/bin/python yolo_phone/local_demo/start.py
```

打开命令输出的本机网址（通常为 http://127.0.0.1:8765）。
可开启摄像头、选择或拖入图片/视频、调整置信度阈值、保存当前检测结果图。
首次开启摄像头时由你在浏览器中允许权限；视频建议使用浏览器支持的 MP4（H.264）。
摄像头仅申请视频，不申请麦克风。视频按浏览器播放进度抽帧检测。
预览按摄像头/视频的原始帧独立刷新，推理仅提交最新的缩小帧，不等待固定 120 毫秒。
实时推理上传最长边 640，模型推理尺寸仍固定 640；预览最长边 1280。
页面分别显示画面帧率、实际检测帧率、端到端延迟与模型推理耗时。
30 FPS 测试视频在当前电脑的浏览器中实测预览及检测均约 30 FPS；摄像头帧率需以实际设备为准。
点击“停止检测”或关闭页面会关闭摄像头；后台模型服务可用以下命令停止：

```bash
./.venv/bin/python yolo_phone/local_demo/stop.py
```

`runtime.json` 保存实际端口及本次服务标识；`server.log` 保存启动和错误日志。
无需新增 Python Web 框架依赖，使用现有环境与标准库运行。

模型训练样本主要来自固定车内视角；电脑正面摄像头、不同背景、距离及持机姿态
可能与训练分布差异很大。同数据集的图像级命中率不能代表真实摄像头检测效果。
提速不会提高模型泛化能力。若继续训练，应先明确实际部署视角，再采集并人工标注
该场景的独立训练/评估数据；不要直接把低置信或漏检画面当背景。
