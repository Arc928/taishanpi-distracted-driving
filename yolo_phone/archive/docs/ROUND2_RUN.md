## 排除的两个假设

**分辨率**：用第一轮权重对 5 位验证司机跑 640/960/1280，640 最优。
calling@0.5 命中 108/131 → 100/131 → 42/131。训练和推理固定 640。

**候选筛选质量**：未进第一轮的 147 张 calling 高置信样本全部满足
「唯一正确类别框、置信度 ≥0.8、无 ≥0.5 错类竞争框」，筛选规则本身无误。

## 训练与评估

从第一轮权重 `runs/selftrain_round1_yolo11n/weights/best.pt` 继续训练，
20 epoch、640、batch 8、MPS，输出 `runs/selftrain_round2_yolo11n`。

随后运行：

```bash
./.venv/bin/python yolo_phone/check_validation.py \
  --weights yolo_phone/runs/selftrain_round2_yolo11n/weights/best.pt \
  --output yolo_phone/validation_round2
```

对比重点：calling 全局命中率，以及 p081 / p015 / p050 的漏检是否减少。
第一轮基线（0.5 阈值）：texting 130/136、calling 108/131、背景误报 11/377。
