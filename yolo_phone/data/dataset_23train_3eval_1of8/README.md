# 1/8 抽样基础集：23 train / 3 eval

旧 `dataset/` 已归档到 `../archive/data/dataset/`，旧标注和阶段记录也保存在 `../archive/`。
当前脚本默认读取本目录；本目录的图片、标签及评估快照保持原样。

2026-10-09 按用户确认的司机划分构建。独立评估司机为 **p016、p021、p026**，
其余 23 位为训练司机，包括旧验证集中的 p039、p081。评估目录名沿用 YOLO 的 `val`。

| split | 司机数 | texting | calling | 背景 | 合计 |
|---|---:|---:|---:|---:|---:|
| train | 23 | 507 | 512 | 1455 | 2474 |
| val（eval） | 3 | 96 | 92 | 264 | 452 |
| 合计 | 26 | 603 | 604 | 1719 | 2926 |

抽样规则保持不变：seed=42，每位司机的每个源类别随机保留 `ceil(数量 / 8)` 张，
并非按时间抽帧。抽到的源图集合与旧 `dataset/` 完全相同。图片均为软链接。

这是标注前的基础集。新目录未迁移旧检测框，正样本标签文件暂缺，
1207 张待标注图片列在 `annotation_queue.csv`；背景为空标签。
**不能直接训练**，否则缺框正样本会被训练程序当作背景。
独立评估同样缺少正样本真实框，目前不能计算真实检测 mAP。

后续仅从本目录 `manifest.csv` 的 `split == 'train'` 中选择训练样本。
复用历史标注时也须核对该新清单，p016、p021、p026 的图片一律不进入训练。
旧合并与评估脚本仍默认读取旧 `dataset/`，需适配新路径和司机名单后使用。
旧数据、人工标注、预测结果原样保留；若后续训练使用 p039、p081，
旧五位司机的汇总结果不能再作为该模型的独立评估。

`summary.json` 保存抽样参数、源 CSV 哈希与类别统计；`verification.json` 保存构建核验结果。
`eval_files_sha256.json` 为新评估图像及现有背景标签的快照，后续补画评估框时需另存更新后的快照。

重建命令（已有目录会拒绝覆盖，重跑须另取输出名）：

```bash
./.venv/bin/python yolo_phone/prepare_dataset.py \
  --sample-every 8 --seed 42 --val-subjects p016 p021 p026 \
  --output yolo_phone/dataset_23train_3eval_1of8
```
